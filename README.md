# 透明時刻 Clear Moment｜AI 售後服務夥伴 Demo

2026 和泰 AI 黑客松提案「運用 AI 再造 TOYOTA 下一代顧客售後服務體驗」的互動 Demo。第一次打開也能跟著畫面上的提示一步一步操作，約 3 分鐘看完；也可以配合簡報逐頁演示。

**線上展示：** https://leolo1205.github.io/toyota-ai-hackathon-demo/

> 本 Demo 為參賽提案的概念示意，**非 TOYOTA／和泰汽車官方服務**。畫面中的車輛資料、保養紀錄、報價、知識庫、服務據點與電話皆為虛構；介面僅參考現行系統的版型，未使用官方商標與插圖。AI 產生的內容為預先寫好的示範文字，不會呼叫任何 AI 服務，也不需要帳號。

## 怎麼操作

1. 打開網頁，按「**開始體驗 ▶**」（或點三張功能卡片，直接跳到想看的功能）。
2. 每一步上方會寫「**請操作**」：要點哪裡，畫面上會出現紫色的「**點這裡**」標示並閃爍紫框。
3. 不想自己找，就按「**幫我點一下**」；點到別的分頁找不到目標時，它也會先把畫面帶回來。
4. 做完會出現綠色的「**完成**」與「**結果在這裡**」，按「**下一步 →**」繼續。
5. 共 10 步、分 3 個功能，最後有總結頁，可以重新開始。

畫面說明：

- 左邊是服務專員的平板（和泰現行工單系統示意），右邊是車主的手機（官方 LINE、My TOYOTA App 示意）。
- **紫框＋「提案」標籤**是我們新增的 AI 功能；**淡灰色**是現有系統。
- 鍵盤 `←` `→`（或簡報遙控器的上一頁、下一頁）也可以切換步驟。

### 手機、平板

- 螢幕寬度小於 900px 時，一次只顯示一台裝置，上方可切換「服務專員的平板／車主的手機」；要操作的地方在另一台裝置時，會自動切換過去。
- 「請操作」說明和按鈕固定在畫面底部，捲動時也看得到。
- 簡報演示建議用電腦全螢幕（F11），1366×768 以上可以一頁放下。

## 提案的三項功能

| 功能 | 嵌入的現有系統 | Demo 中的位置 |
|---|---|---|
| ① AI 維修翻譯官 | 服務廠平板工單、官方 LINE | 專員口述檢查結果 → AI 產生白話說明 → 車主在 LINE 確認施作、追問；議價等複雜問題轉專員；中間報告線上確認 |
| ② 智慧客休體驗 | My TOYOTA App | 今日回廠進度與等待建議、車況圖解、個人化用車知識 |
| ③ 個人化售後關懷 | App 保修紀錄、官方 LINE | 交車服務摘要、交車後關懷與 AI 分流、保養提醒與一鍵預約 |

## 程式說明

`index.html` 的 `<script>` 主要分成以下幾段：

- **示範資料**：車輛、保養紀錄、工單報價與檢查結果（`V`、`QUOTE`、`INSP`）。
- **示範內容**：依檢查數值組合白話說明、服務摘要、知識卡（`fbTranslate`、`fbSummary`、`fbKnowledge`），追問依關鍵字回覆（`fbAnswer`）。
- **模擬 AI**：按下按鈕後先顯示「產生中」，再顯示預先寫好的內容（`fake`、`doTranslate`、`doAsk` 等）。
- **步驟**：每一步的標題、對應簡報頁、現行與提案對照，以及要操作的元素與完成條件（`SCENES`、`curStep`、`goScene`）。
- **導覽**：「點這裡」指標、「幫我點一下」、窄螢幕自動切換裝置（`placePointer`、`helpMe`、`reveal`）。
- **畫面**：平板工單（`tablet`、`tabContent`）、官方 LINE（`lineChat`、`liffBook`）、My TOYOTA App（`appHome`、`appProgress`、`appRecords`）。

實際導入時，「模擬 AI」這段會換成串接大型語言模型、知識庫檢索（RAG）與工單系統 API。
